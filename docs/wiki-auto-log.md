# XML 위키 자동 갱신 기록

노트북의 Claude 예약 작업 `hotscrap-data-watch`(매일 08시대)가 게임 설치본이 새 판인 것을 보면
`update_wiki.py` 로 영웅 자료부터 위키까지 다시 만들어 **자동으로 올리고**, 여기에 달라진 점을 적는다(새 것이 위).
올리기 전 검사(영웅 수가 줄었나, 위키 파일이 비었나, 지운 줄이 너무 많나)에 걸리면 올리지 않고 알리기만 한다.
위키 화면의 '위키 변경 기록'(대문 맨 아래)에도 같은 판이 버전으로 남는다.
