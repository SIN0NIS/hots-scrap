게임용 파일 · 리플레이 인터페이스

hots-scrap-obs

게임 안에서 리플레이를 볼 때 쓰는 화면(인터페이스)입니다. 한국어판(KOR)과 영어판(ENG)이 있습니다. 왼쪽 위 [메뉴] 버튼 하나로 원하는 것만 켜고 끕니다.

  • 화면 — 상단바·미니맵·채팅창·리플레이 컨트롤·유닛 정보·알림을 하나씩, 또는 UI 전체를 켜고 끄기
  • 머리 위 이름 — 유저 이름 대신 영웅 이름으로 바꿔 보기
  • 상단바 모드 — 영웅마다 네모 카드에 특성(1~20레벨)·궁극기 쿨다운·체력·자원, 스킬 쿨다운(쓸 수 있으면 밝게, 쿨다운 중이면 회색과 남은 초)
  • 체력바 숫자 — 현재/최대 체력과 퍼센트, 쉴드는 막대 옆에 +숫자로 따로

게임용 프로그램 · 리플레이 시야 조절

hots-scrap-custom-viewer

리플레이를 볼 때 카메라를 원하는 각도로 돌려 흔들림 없이 고정하고, 줌을 더 멀리·더 가까이 보는 작은 프로그램입니다. exe 하나만 받아 실행하면 되고, 파이썬이나 다른 프로그램은 필요 없습니다.

  • 각도 — 일반 전장은 ±180° 안에서 슬라이더·숫자 입력·±1°로 정하고 그 자리에 고정, 무작위·난투는 게임 한계인 ±45°
  • 줌 — 일반 전장은 12단계(기본에서 멀리 5 · 가까이 6), 무작위·난투는 관전 줌 1·2
  • 리플레이 열기 — 창에서 최근 리플레이를 골라 열면 임시 변환본으로 열리고, 리플레이를 나가는 순간 자동으로 지워집니다. 원본은 건드리지 않습니다.
  • 처음 한 번 — 창 아래 [회전 키 설정]을 게임을 끈 상태에서 누르면 카메라 회전 키(Insert/Delete)가 켜집니다.

Windows 전용입니다. 처음 실행할 때 SmartScreen 경고(서명 없는 exe)가 뜨면 추가 정보 → 실행을 누르세요. 쓰는 법은 GitHub 페이지에 있습니다.
